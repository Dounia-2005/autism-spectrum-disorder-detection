## 📌 Project Overview

This project investigates the detection of Autism Spectrum Disorder (ASD) by combining statistical analysis and supervised Machine Learning techniques.

Unlike traditional classification projects that focus only on predictive performance, this study also evaluates whether statistical relationships and Machine Learning models remain consistent across two independent ASD datasets.

The project includes exploratory data analysis, statistical hypothesis testing, feature analysis, supervised learning, cross-validation and cross-dataset evaluation.

---

## 🎯 Objectives

- Compare two independent Autism Spectrum Disorder datasets.
- Perform descriptive and inferential statistical analyses.
- Identify variables significantly associated with ASD.
- Develop and evaluate multiple supervised Machine Learning models.
- Assess model robustness using 5-fold cross-validation.
- Evaluate model generalization across independent datasets.

The project follows the workflow below:

2. Exploratory Data Analysis (EDA)

4. Feature analysis
5. Machine Learning model development
6. Hyperparameter tuning

9. Performance comparison

---

## 📊 Statistical Analysis

The statistical study investigates the consistency of the relationships between explanatory variables and Autism Spectrum Disorder across two independent datasets.

The analysis includes:

- Descriptive statistics
- Correlation analysis
- Normality assessment
- Statistical hypothesis testing
- Comparative analysis between datasets

---

## 🤖 Machine Learning Models

The following supervised learning algorithms were implemented and evaluated:

- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- K-Nearest Neighbors (KNN)
- Decision Tree

Each model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- 5-fold Cross-Validation

The study also evaluates model generalization using an independent external dataset.
